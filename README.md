A full desktop management system built using C# and WinForms that simulates a Driving & Vehicle License Department (DVLD).
The system manages driver licenses, applications, tests, renewals, replacements, and detain/release operations with a multi-layer architecture

Features:
.Manage people and drivers

.Issue Local Driving Licenses

.Renew Licenses

.Replace Lost or Damaged Licenses

.Schedule and manage driving tests (Vision, Written, Practical)

.Retake failed tests

.Issue International Licenses

.Detain and Release licenses

.Application management system

.Multi-layer architecture (Presentation Layer, Business Layer, Data Access Layer)

.SQL Server Database integration

.Validation and business rules implementation

Technologies Used:
.C#

..NET Framework

.Windows Forms (WinForms)

.SQL Server

.ADO.NET

.3-Tier Architecture

Project Purpose:
This project was built as a practical implementation of OOP principles, database design, and layered architecture in a real-world simulation system
